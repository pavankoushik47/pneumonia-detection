# 🫁 Pneumonia Detection

An 🤖 AI-powered deep learning project that detects **Pneumonia** from chest X-ray images using a **VGG16** model.

## 📌 Overview

This project uses 🧠 **Deep Learning** and 🖼️ **Image Classification** techniques to analyze chest X-ray images and classify them as:

- 🫁 **Pneumonia**
- ✅ **Normal**

The model is integrated with a simple 🌐 **Streamlit web application** for easy image-based prediction.

## 🛠️ Technologies Used

- 🐍 Python
- 🧠 TensorFlow
- 🔥 Keras
- 🏗️ VGG16
- 🌐 Streamlit
- 👁️ OpenCV
- 🔢 NumPy

## ✨ Features

- 📤 Upload chest X-ray images
- 🧠 AI-based pneumonia detection
- 🔍 Image classification
- 📊 Prediction results
- 🌐 Simple and interactive Streamlit interface
